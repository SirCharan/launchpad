# fuckpump

Token launchpad with continuous clearing auctions. DeFi-native, onchain token distribution and liquidity bootstrapping — themed void, hellfire, and pill lord.

**THE PILL WEARS THE CROWN. GOONFI ETERNAL.**

## What it is

- **Discover** — Browse tokens and auctions, place bids, claim tokens
- **Launch** — Commit supply, set duration and floor price, run a public auction
- **Token** — Per-token pages: price discovery, bids, swap, and Uniswap v4–style liquidity

Aligned with [Uniswap CCA](https://cca.uniswap.org/) (Continuous Clearing Auctions): fair, market-driven, transparent onchain distributions.

## Stack

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS 4**
- **Radix UI** + shadcn-style components
- **TypeScript**

## Getting started

```bash
# Install
bun install

# Dev
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
# Build
bun run build

# Start (production)
bun run start
```

## Scripts

| Script   | Description        |
